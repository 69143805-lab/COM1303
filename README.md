รายวิชา: COM 1303 การพัฒนาเว็บขั้นพื้นฐาน

1. Git คืออะไร
   
 Git คือระบบเก็บประวัติไฟล์โค้ด คล้ายๆ จุดเซฟเกมครับ ถ้าโค้ดพังก็ย้อนกลับไปเอาอันเก่ามาใช้ได้ และช่วยให้ทำงานกลุ่มพร้อมเพื่อนหลายคนได้โดยที่ไฟล์งานไม่ทับกัน

 2. การทำงานของเว็บไซต์ทำงานอย่างไร

 เมื่อเราพิมพ์ชื่อเว็บ เบราว์เซอร์ (Client) จะส่งคำขอไปที่เซิร์ฟเวอร์ (Server) จากนั้นเซิร์ฟเวอร์จะประมวลผลแล้วส่งข้อมูลกลับมาให้เบราว์เซอร์โชว์เป็นหน้าเว็บให้เราดูครับ

 3. เว็บไซต์ต่างจากเว็บแอพพลิเคชั่น อย่างไร

3.1 เว็บไซต์: เน้นให้คนเข้ามาอ่านข้อมูลทางเดียว โต้ตอบไม่ค่อยได้ เช่น เว็บข่าว

3.2 เว็บแอปพลิเคชัน: ทำงานซับซ้อนเหมือนโปรแกรมใช้งานจริง ล็อกอินได้ สั่งของได้ เช่น Facebook หรือ Shopee

4. คู่มือการใช้งาน Github

   1.ดาวน์โหลดและติดตั้ง github desktop

   2.เข้าสู่ระบบ github desktop

   3.เลือกเมนูซ้ายบน

   -เลือกcreate repository

   -ใส่ชื่อ

   -เลือกว่าจะเก็บในไดฟ์ไหน

   -กดcreate repository

   -กด publish เพื่ออัพขึ้นGithub
